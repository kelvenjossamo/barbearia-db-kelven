# Modelo relacional — BarbeariaPK = chave primária (sublinhada no ER) · FK = chave estrangeira|Tabela|Atributos||-|-||**cliente**|**id\_cliente (PK)**, nome, telefone (único), email, data\_registo||**barbeiro**|**id\_barbeiro (PK)**, nome, telefone (único), especialidade, data\_admissao||**servico**|**id\_servico (PK)**, nome (único), preco, duracao\_min||**utilizador**|**id\_utilizador (PK)**, username (único), senha\_hash, perfil, id\_cliente (FK → cliente), id\_barbeiro (FK → barbeiro)||**marcacao**|**id\_marcacao (PK)**, id\_cliente (FK → cliente), id\_barbeiro (FK → barbeiro), data\_hora, estado, observacoes · único (id\_barbeiro, data\_hora)||**item\_marcacao** *(entidade fraca)*|**id\_marcacao (PK, FK → marcacao)**, **num\_item (PK)**, id\_servico (FK → servico), preco\_aplicado|## Cardinalidades* cliente 1 — N marcacao (participação total de marcacao)* barbeiro 1 — N marcacao (participação total de marcacao)* marcacao 1 — N item\_marcacao (identificador da entidade fraca; participação total)* servico 1 — N item\_marcacao* cliente 0..1 — 1 utilizador e barbeiro 0..1 — 1 utilizador (conta de acesso ao sistema web)## Entidade fraca`item\\\\\\\_marcacao` não tem identificador próprio: depende de `marcacao`. A chave é composta: (id\_marcacao, num\_item).
